# Predefined Macros Information (C)

## Project Description

This project demonstrates the use of predefined macros available in the C preprocessor. The program displays information such as the compilation date, compilation time, source file name, current line number, and whether the compiler follows the standard C language.

It is a simple program for understanding how predefined macros work before the actual compilation of a C program.

## Features

- Displays the compilation date
- Displays the compilation time
- Displays the source file name
- Displays the current line number
- Displays the standard C indicator
- Demonstrates predefined preprocessor macros

## Technologies Used

- C Programming Language
- C Preprocessor
- GCC Compiler

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Compile the program:

```bash
gcc predefined_macros.c -o predefined_macros

./predefined_macros

Predefined Macros Used
__DATE__ - Gives the compilation date.
__TIME__ - Gives the compilation time.
__FILE__ - Gives the current source file name.
__LINE__ - Gives the current line number.
__STDC__ - Indicates standard C conformance when supported by the compiler.
